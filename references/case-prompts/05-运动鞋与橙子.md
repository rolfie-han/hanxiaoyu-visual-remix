# 运动鞋与橙子

使用这两张真实传入的参考图创作竖版3:4大胆超现实产品广告概念，单幅无文字。图1是需要保留的运动鞋：奶白网面、蓝色弧形侧片、橙色后跟拉环、白鞋带和灰色外底，保留可辨产品造型，不能改成橙子做的鞋。图2是材料与结构：普通半个橙子，保留橙皮粗糙质感、白色内皮、放射状果肉与汁胞。构图概念：这只鞋把一个巨型橙子踩成了弹力蹦床，像从鲜榨能量里弹射出来。巨型橙子横切面倾斜面对镜头，成为半球形立体舞台，果肉在鞋底受压处呈可信超现实凹陷，橙皮边缘像柔韧弹簧卷成一段向上弯曲的起跳坡道；鞋前掌压在果肉坡道边缘、后跟扬起，方向从左下向右上，鞋侧面清楚。少量鲜亮橙汁受压形成一条明确弧线与透明水珠，从鞋后方绕向前景，不能乱飞遮住鞋。不加人物脚腿，不多鞋，不变成简单鞋与水果并排静物，不只换背景。深钴蓝纯净空间，橙黄果肉逆光晶莹，奶白蓝橙鞋子成为绝对主角，低机位广角微距，巨大前景果肉与远处细小水滴构成立体纵深，高速闪光摄影结合精致三维广告渲染，物理材质细节清楚，强烈有趣、可用于运动活力主题概念海报，无logo水印。
