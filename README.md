# 韩小羽 · 视觉改造 Skill

把普通图片与日常需求，变成个人海报、宠物趣图和商品创意作品。

## 下载

- [完整 Skill](https://github.com/rolfie-han/hanxiaoyu-visual-remix/releases/download/v0.2/hanxiaoyu-visual-remix-v0.2.zip)
- [12个案例完整提示词](https://github.com/rolfie-han/hanxiaoyu-visual-remix/releases/download/v0.2/all-case-prompts-v0.2.zip)
- [在线查看案例提示词](references/case-prompts-index.md)

## 使用

下载并解压 Skill，保留整个文件夹，在支持 Skill、参考图片与图像生成的工具中安装或导入。

上传图片后说：“使用 $hanxiaoyu-visual-remix，把这两张图组合成一张有趣的作品，保留我的人或物，其他你来设计。”

完整提示词包仅包含12个案例各自的提示词，其中11个为双图创作，1个为文字创作。
